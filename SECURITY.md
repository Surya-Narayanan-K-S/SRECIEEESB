# Security Policy

## Supported Versions

We actively maintain and provide security updates for the current major version of the IEEE SREC Web Ecosystem.

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| 1.x.x   | :x:                |

---

## Reporting a Vulnerability

The IEEE SREC Web Development Team takes the security of our platform and member data seriously. If you discover a security vulnerability within this repository, please follow these steps:

1. **Do NOT disclose the issue publicly** (e.g., via GitHub Issues, public social media, or forum discussions).
2. Email the maintainers directly at:
   - **Email**: `ieee@srec.ac.in`
   - **Subject**: `[SECURITY VULNERABILITY] IEEE SREC Portal`
3. Please include:
   - A detailed description of the vulnerability.
   - Steps to reproduce the issue (proof-of-concept scripts or screenshots where applicable).
   - The potential impact of the issue.

---

## Response Timeline

- **Acknowledgment**: We aim to acknowledge receipt within 48 hours.
- **Assessment**: We will triage and assess severity within 5 business days.
- **Resolution**: Critical fixes will be deployed as soon as verified.
